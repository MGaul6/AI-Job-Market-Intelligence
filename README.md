# AI Job Market & Skill Intelligence Dashboard

## Overview
This project focuses on analyzing AI/ML job market trends, in-demand skills, salary insights, and hiring patterns using Power BI and Python.

The goal of this project is to generate data-driven insights into the evolving AI industry and understand the technologies and skills most demanded in the current job market.

---

## Tech Stack
- Power BI
- Python
- Pandas
- Data Visualization
- Exploratory Data Analysis (EDA)

---

## Planned Dashboard Features
- AI/ML job trend analysis
- Most in-demand AI skills
- Salary trend visualization
- Regional hiring insights
- Python vs R demand comparison
- Industry-wise AI hiring patterns

---

## Dataset Sources
- Kaggle datasets
- Public job posting datasets
- AI job market datasets
